2016 Volkswagen Golf GTI website

Files:
- index.html: the single-page website structure and content
- style.css: colors, layout, typography, and responsive styling
- images/: your supplied GTI photos used by the website

To view locally:
1. Keep index.html, style.css, and the images folder together.
2. Open index.html in a web browser, or open the folder in Visual Studio Code.

To publish:
1. Create a GitHub repository for the project.
2. Upload index.html, style.css, and the entire images folder.
3. In the repository, open Settings > Pages.
4. Set deployment to the main branch and the root folder, then save.
5. Use the URL GitHub Pages provides.

Note: The Google Fonts import is optional. If offline, the page uses fallback fonts.
